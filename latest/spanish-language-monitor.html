How this material was gathered

Pipeline (LEM-ES-MIA lane): each station's public live stream is captured in scheduled ~12-minute windows during talk programming (ffmpeg). The Spanish audio is transcribed with faster-whisper (Spanish ASR, run locally), machine-translated to English (local qwen2.5:14b), and the translation is analyzed by the same Conspiracy Today analyzer that scans SignalWatch's other sources — a translate-then-classify design, so Spanish-language content is judged by the identical narrative criteria as English content. This lane is an isolated probe: its findings are reported here and do not mingle with the main corpus.
Limitations, honestly: capture windows are samples, not continuous monitoring, and talk radio carries heavy ad blocks — some windows are mostly advertising. 3 of 35 capture windows produced empty or too-thin transcripts (stream or transcription failure) and are excluded; we found that the analyzer can hallucinate generic conspiracy titles when handed an empty transcript, so every narrative on this page is additionally required to be grounded in its window's transcript text. ASR and machine translation introduce their own errors; quotes are translated excerpts, not verbatim English speech. A narrative appearing on a program documents what went to air in that window — it is not a claim about a station's editorial position, and never a verdict about any individual.
